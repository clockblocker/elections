# Interactive Shpilkin analysis

An evidence-first application for exploring Russian federal election results using turnout distributions and Shpilkin-style excess-vote estimates.

The first vertical slice covers the 2021 State Duma election. See [WAYFINDER.md](WAYFINDER.md) for the delivery plan and [docs/data-sources.md](docs/data-sources.md) for the current source inventory.
